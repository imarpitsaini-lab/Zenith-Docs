Permissions Disclosure

Effective Date: 15 January 2026

Zenith is designed with a privacy-first approach. Every permission requested by the application is required to enable a specific feature. Zenith never requests unnecessary permissions and never sells or shares your personal data.

Permissions Used by Zenith

1. Accessibility Service

Purpose
  • Detect when a protected application is opened.
  • Display the blocking screen after daily limits expire.
  • Run Deep Focus sessions.
  • Display the floating countdown timer.
Zenith DOES NOT
  • Read messages.
  • Read passwords.
  • Record your screen.
  • Capture keyboard input.
  • Monitor personal conversations.

2. Usage Access Permission

Purpose
  • Calculate app usage duration.
  • Generate productivity analytics.
  • Track remaining daily limits.
  • Display Insights Dashboard statistics.

3. Display Over Other Apps

Purpose
  • Show the blocking screen.
  • Show the floating timer.
  • Display Focus Mode overlay.

4. Notification Permission

Purpose
  • Focus session reminders.
  • Update notifications.
  • Background service notifications required by Android.

5. Foreground Service

Purpose
  • Keep app tracking active.
  • Maintain timer accuracy.
  • Prevent Android from stopping active monitoring.

6. Receive Boot Completed

Purpose
  • Restore protection after device restart.
  • Reload protected apps automatically.

7. Ignore Battery Optimization (Optional)

Purpose
  • Improve timer accuracy.
  • Prevent Android from killing Zenith in background.

This permission is optional but recommended for the best experience.

Data Storage

  • All protected app information is stored locally on your device.
  • Analytics remain on your device.
  • No cloud account is required.
  • No personal information is uploaded to Zenith servers.

Remote Update Check

Zenith periodically checks a publicly hosted JSON file on GitHub to determine whether a newer application version is available. Only the application version information is downloaded. No user information is transmitted during this process.

Your Privacy

Zenith never collects:

  • Passwords
  • SMS Messages
  • Photos
  • Videos
  • Contacts
  • Call History
  • Location
  • Banking Information
  • Clipboard Data
  • Microphone Audio
  • Camera Images
